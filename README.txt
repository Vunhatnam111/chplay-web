CHPLAY WEB
==========

Đây là website mô phỏng cửa hàng ứng dụng.

CÁCH CHẠY
----------

1. Mở file index.html bằng Google Chrome.

2. Không cần cài phần mềm.

3. Có thể chạy trên máy tính hoặc điện thoại
   thông qua website online.


CẤU TRÚC
--------

index.html
style.css
script.js
robots.txt
sitemap.xml


ĐƯA LÊN GITHUB PAGES
--------------------

1. Tạo tài khoản GitHub.

2. Tạo repository mới.

   Ví dụ:

   chplay-web

3. Upload toàn bộ file:

   index.html
   style.css
   script.js
   robots.txt
   sitemap.xml
   README.txt

4. Vào:

   Settings
   -> Pages

5. Chọn:

   Deploy from a branch

6. Chọn:

   main
   /
   root

7. Nhấn Save.


WEBSITE
-------

Sau khi GitHub hoàn tất, website sẽ có dạng:

https://TEN-GITHUB.github.io/chplay-web/


GOOGLE
------

Để Google có thể lập chỉ mục website:

1. Website phải được đưa lên Internet.

2. Đăng ký Google Search Console.

3. Thêm địa chỉ website.

4. Gửi sitemap.xml.

5. Chờ Google thu thập dữ liệu.


LƯU Ý
-----

Website này là giao diện mô phỏng.

Nút "Cài đặt" không thực sự cài ứng dụng.

Khi nhấn "Cài đặt", website sẽ hiển thị:

"DUNG LƯỢNG ĐÃ ĐẦY"
